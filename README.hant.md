### 一鍵登入（Access Token）

**不接受手動貼上 sk-**。憑證是控制台 **Access Token**；登入後自動申領並持久化 relay sk-。

```text
/login /login access <token> /login oauth
/console balance|models|tokens|logs|topup|…
```
